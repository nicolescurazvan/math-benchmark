# math-benchmark

Math-inspired CPU benchmark. It tests the CPU on mathematical tasks.

Single-threaded benchmarks:
1. Prime finding
2. Euler conjecture disprover (k = 4, n = 5)
3. Matrix multiplication
4. Irreducible polynomial finding over the integers
5. Irreducible polynomial finding over finite fields
6. Dedekind function counting
7. Collatz pruning
